# 本地模型配音：复用入口与剪辑交接

用途：从共享工作流找到配音能力，复用已验收参考、逐句生成与局部回改。

## 权威入口与存放边界

本仓库保存流程索引、模型调用方式和剪辑交接约定。`clark-spoken-delivery` 技能和通用脚本在 `skills/` 中维护；本机安装可通过目录联接读取同一份源文件。

- [口播与本地代配音技能](../skills/clark-spoken-delivery/SKILL.md)：改稿、情绪、重音与试听规则。
- [本地代配音流程](../skills/clark-spoken-delivery/references/local-voice-production.md)：参考录音、模型选择、逐句重做及验收。
- [本机 CLI 配方](../skills/clark-spoken-delivery/references/local-voice-cli.md)：版本、参数、批量调用、离线设置及排错。
- [通用推理脚本](../skills/clark-spoken-delivery/scripts/local_voice.py)：单句与批量生成。运行前按技能核查选中引擎和依赖。
- Python 与模型根目录：从本机私有配置定位；所需模型子目录为 `VoxCPM2` 或 `Qwen3-TTS-12Hz-1.7B-Base`，不要混用通用剪辑环境。
- 媒体后处理：从本仓库 `components.json` 定位 FFmpeg/ffprobe。`editing_env` 不是配音推理环境，不混用。

配音环境与权重不在本仓库组件清单的哈希核验范围内；目录存在不代表权重完整或推理验收通过。克隆本仓库包含技能源码，但不会自动安装技能、环境或权重，换机器须按技能重新核实。

录音、参考转写、音色特征、待配稿、生成音频、批量任务清单和推理收据保存在各项目的本地私有目录，不提交到公共仓库。通用方法文档不嵌入私人内容。

## 模型路线

配方支持 **VoxCPM2 和 Qwen3-TTS**。具体主用与备选选择留在本地项目记录；后续相似任务优先用当前项目代表句检查既有方案，不将历史选择写成所有题材的最佳模型，也不默认每次重做完整模型选型。

这里实现参考录音/文字条件下的音色推理，**不包含参数微调**。具体环境版本和已实跑范围以技能 CLI 文档为准；裁剪过的环境存在未安装可选依赖，不能宣称全部依赖检查通过，也不应为消除提示自动安装全部包。

## 从文稿到成片

1. 从当前项目入口查已认可的声音参考和配音清单。参考录音须干净自然、转写准确对应选段；跨项目复用先确认适用，不把旧路径硬编码成新项目默认。
2. 用稳定句 ID 保存朗读文字、字幕文字、情绪/重音备注、画面对象和画面锚点。只有朗读文字送入推理，备注不念；不擅加笑声、感叹或虚构现场反应。
3. 先生成当前任务需要的代表句，试听音色、地名/数字、自然度、情绪与停顿。已有合格参考只做必要检查，再批量生成。
4. 优先使用通用脚本批量入口，一次加载模型、串行生成句子。保留原始 WAV 和收据，再按项目需要制作剪辑用音频；不靠机械加速挽救不自然的句子。
5. 本地 ASR 辅助查漏字、重复和读音；实际回听核查音色、伪影和前后衔接。ASR 正确或导出成功均不等于听感通过。
6. 按实测音频时长交给剪辑，结合画面、现场对白与自然声调整时间线。预览与正式母版引用明确版本的音频，不使用漂移的“最新文件”。

现场真实对白与后期旁白分开保存。Tesseract、MLT 或 Premiere 作为剪辑端都可以使用配音产物；更换剪辑端不意味着更换音色生成方案。每个新剪辑端仍须验证音频导入、起止点、淡入淡出与最终同步。

## 局部修改和可复现记录

- 只改字幕或不影响朗读的备注，不重新生成声音。
- 改了一句时保留句 ID，生成独立新版；模型需要上下文时重做最小完整语义段。删除文字且原音频有自然断点时，可先剪接，但必须试听衔接。
- 记录文案、参考内容标识及参考转写、模型/权重/代码版本、推理模式、种子、参数与后处理；相关输入变化才考虑失效，不能仅凭文本相同复用旧缓存。
- 脚本拒绝覆盖已有 WAV/JSON，调用方负责判断复用；相同种子不保证跨环境逐位一致。批量失败保留已完成输出，只重试未完成或需要修正的句子。
- 剪辑交接至少包含句 ID、音频路径及版本/哈希、实际时长、字幕文字、画面锚点、与现场声的关系及试听状态。这些带私人内容的清单保存在项目内。
- 仅技术检查通过、实际人耳已听、用户已认可分别记录，不合并成一个“通过”。

## 在新方案实验中的位置

比较剪辑/动效工具时，**固定本地配音模块**：各方案使用同一份已认可的配音文件与字幕，不重新生成不同音频混入比较。

配音准备成本作为共享上游成本单列，不在每个剪辑方案重复累计。重点比较同一音频的导入、对齐、修改后的重接和声画效果。若以后确实比较本地配音模型或参考策略，另做独立实验：固定稿件和尽量可比的参考/后处理，记录首次加载、生成耗时、失败重做、显存、可计量成本，并用本地隐藏模型身份的试听比较音色相似度、准确性、自然度和情绪。没有数据的成本标未知，不把本地推理说成零成本。

## 本地执行边界

声音、转写、音色与生成音频仅本地处理保存，不上传外部模型服务或公共仓库。已有 CLI 的离线变量与 Python socket 限制不是系统防火墙保证，执行时仍须核查路径与联网行为；缺权重/依赖不得临时联网补齐。下载遵循工作区不走 VPN、不改全局代理及路由不明则停止询问的约定。

先查 GPU 占用，不中断无关任务；不并行加载两套语音模型挤占显存。没有 CUDA 或关键依赖时按实际错误处理，不隐式改成另一条未经验证的路径。

# 本地科普动画入口

用于给真实画面补充不易看见的过程、制作本地模型底图或修改科普特效。先明确观众要理解的问题和事实边界，再选择生成底图、描线、粒子、箭头与短标签；不能用精致插画或装饰运动替代解释。

共享方法见仓库内的 [本地模型插画与科普动画](../../../docs/local-science-animation.md)。通过技能目录联接访问时，先解析技能真实位置，再定位仓库根目录。

该文档指向已保存的 FLUX.2 Klein API 图、提示词、石灰岩示例和可按目标尺寸重绘的脚本。需要本地生成时另读当前 `comfyui` 技能核服务、节点、模型与队列；复盘或改标签不启动模型。权重、素材、私人声音和生成产物留在本地项目。

复用边界：本次是模型静态底图加程序动画，没有视频模型或物理模拟；八秒、三个阶段、粒子语义、坐标与模型参数均属具体案例。新原理重新核事实和布局，新口播重新对齐阶段。中文标签由程序绘制，制作说明不进入成片，观众需要的科普文字可以保留。4K 用原素材及目标尺寸图层重建，不能整体放大审片代理。

已有风格选择和阶段授权继续适用；局部先检查前后语义，再按任务需要复核，不为这套方法新增固定审批轮次。

# 项目状态与增量审片

用于新项目的约束整理、多轮反馈和时间线更新。已有等价字段和记录时沿用，不另建一套平行系统。

## 最小有效状态

当前入口只保留正在执行的版本：时间线及其内容标识、有效稿件/字幕/声音/工程/预览路径、用户选择、未完成事项。审批记录指明对象与版本，区分剪辑稿、粗剪、精剪代理、最终规格渲染授权；技术检查和用户画质验收另记。局部变化只重新核查受影响范围，不把旧版本的通过状态自动套给新内容，也不要求重审完全未变部分。

AGENTS 保留稳定约束和当前入口；逐轮过程、被替代选择及旧待办进入历史决策，写明由哪条新选择覆盖。一个无范围的 approved 布尔值不能同时表示方案选择、样片验收和整片通过。

本片表达参数按已有决定填写：目标时长与硬上限、信息密度、照片停留、原声保护、配乐进出与连续性、少数留白和结尾方式。分清明确决定、沿用的个人偏好与尚待选择的项，不把所有字段都变成开场问卷。

“高信息密度旅行片”可作为选用示例：先删重复过程/景别，保留新信息与完整对白反应；照片短停留，精髓留白，可直接结束。8分钟、照片≤3秒、某首音乐及其秒点是历史项目参数，只有当前项目采用时才生效。

## 场景稿与语义锚点

用现有场景/镜头/句子 ID 关联以下内容，原片入出点与成片时码分别保存：

- **画面**：正在讲的对象、素材及源区间，允许承接的相关细节或反应镜头。
- **实际口播、实际字幕**：供声音和字幕导出，允许明确的只字幕内容；禁止把工作备注拼入生成文本。
- **剪辑备注**：重音、情绪、揭示次序、音乐/原声避让、视觉呈现和隐私处理。
- **时长预算**：采用实际配音/对白时长和保留的留白，明确整片总时长及距硬上限的余量。

一句话可以跨多个镜头，只要继续承接同一意思。对话的提问与回应一起审阅；保留源区间余量，避免孤立一句失去上下文。压时长依次检查重复信息与景别、布局及赘述，不能用每句加速替代剪辑；确实超硬上限时，在审片中明确取舍，不能静默放宽。用户接受更长版本后同步更新当前预算，历史上限留在旧决策中。

## 同轮风格验证

在既有稿件或粗剪评审中提供一段代表片，可包含照片、现场对白、旁白、配乐及场景转场；已有风格且当前修改不影响它时直接复用。音乐候选保持同画面和接近响度；情绪配音选当前稿中的代表句；解释性特效先验证问题、标签和动画是否对应。

## 接受反馈与局部修改

用户可随口反馈，agent 整理为：所审版本与定位 → 具体动作 → 需保护的画面/声音 → 影响范围 → 处理状态。原话、素材编号或旧时码都可用于定位，剪辑变化后通过 ID 与源区间映射到当前版本。

修改画面、音乐或一句配音时，先检查哪些素材与时序真正受到影响。复用输入和参数未变的缓存，导出该段及必要前后文；只有累积修改或全片确认需要时再交付整片。声音变短后同步画面锚点、字幕时长和章节，不把旧等待长度机械保留。

版本保存时间线、配置、修改记录和独立输出，处理程序按功能复用。缓存绑定源内容、入出点、处理配置及实现版本；只改发布文案等不影响画面的内容，不触发镜头重渲染。

## 首版前检查的责任

自动检查缺失素材/声轨、入出点越界、布局占位、字幕越界、目标时长和编码规格；空白或黑屏若是明确设计应有记录，避免当故障删除。连续看听人物选图、近景路人、现场对白、拼图、口播对象和场景衔接。无法仅用抽帧或 ASR 证明的听感与运动，明确检查覆盖范围，不能把机器通过写成人工完整审片。

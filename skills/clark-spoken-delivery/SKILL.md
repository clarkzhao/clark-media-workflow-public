# 口播与本地代配音

让观众听得懂、跟得上，保留 Clark 的交流感和个人判断。按当前任务直接进入改稿、推理或试听，不把每次使用都变成从部署开始的完整流程。

涉及本机执行、历史已验收参考或工具选择时，若存在 `references/local-machine.private.md`，先读取其中的本地入口；该文件由 Git 忽略，克隆后缺失是正常情况。缺失时从当前项目配置定位，不猜测路径，也不上传其内容。

## 按任务进入

- **改稿或标注表达**：使用下文规则；不启动模型部署、训练或盲测。
- **真人录制或提词器**：按需读取 [真人录制与提词](references/live-recording.md)。
- **本人音色生成、读音修正或局部重做**：读取 [本地代配音流程](references/local-voice-production.md)，优先复用已验收参考和本地环境；有明确问题或比较需求再展开对应验证。
- **已有音频试听**：直接执行下文“试听与交付”；需要重做时再进入代配音流程。
- **量化节奏**：按需读取 [语速分析方法](references/speech-rate-analysis.md)。视频素材、时间线和画质交给 [剪辑技能](../clark-video-editing/SKILL.md)。

用户的录音、转写、音色特征和生成音频只在本地处理、保存，不上传外部服务或公共仓库。模型及大型运行库下载不走 VPN，不修改全局代理或 VPN；不能确认下载路由时停止该下载并询问。具体核查见本地代配音流程。

## 改稿与声画关系

- 按 humanizer-zh 的方法删空话、重复铺垫和模板化转折；保留事实、态度、确定程度及有作用的口头语。用已有具体细节说清楚，没有细节就简洁表达，不补经历、不夸大结论。
- 保留 Clark 的亲切感、个人判断和轻微自嘲，不润色成旅游宣传语，也不为显得自然擅加“哈哈”、感叹或亲昵称呼。幽默按语境放在口播、真实现场反应或字幕中，遵守已确认分工。
- Clark 偏好少说教、少竞争性比喻、少常识复述。避免无关的政策提醒和行为训诫；一句被指出此类问题时检查全稿同类表达。具体场景需要的提醒仍按当前意图判断，不建脱离语境的禁词表。
- 旅行旁白先看画面，再写自己的经历和感受，优先补充画面之外的信息。每句绑定实际画面对象或事件，代词有指向、因果和转折完整；缩短文案不能只剩失去对象的半句。方法参考 [旅行 Vlog 全流程教学](https://www.bilibili.com/video/BV14KoYB2EYe/)。
- 有内容的现场真对话优先保留，后期旁白用于回顾、解释和补充。不为用户编造未说过的聊天回复或现场反应；需要补录或代配的叙述应明确作为后期旁白呈现，不冒充真实聊天。
- 分开保留原话/原始转写、朗读文字、字幕文字与导演备注（画面、语气、重音、停顿）。只有朗读文字送入配音；只出字幕的括号或笑话不念。无明确改写要求时，字幕忠实于实际说话。
- 长句按意思拆开，地名、数字和陌生概念说清楚；保持长短变化，不把完整语义拆碎。事实、个人回忆和推测保持区分，查不到的事实不编入稿。
- 图表数字与口播引用同一事实和单位约定；情绪不能把“平均改善”扩大为“每个人改善”。直观说法能表达清楚时替换术语，必须保留的概念结合当前图解释；模拟设定和结论范围按剪辑技能的定量科普参考处理。
- 有真实依据时，可按“期待 → 实际 → 反应”安排落差和画面揭示，前文不提前说破结果。项目地点、一次措辞偏好和当时场景只用于适用语境，不升级成永久硬约束。

## 情绪、重音与节奏

- 按信息轻重安排快慢：熟悉衔接可快，数字、地名、新概念与关键结论适当放慢，转折留停顿。承接语或短暂自言自语有助理解时保留，不机械删除或定量添加。
- 情绪与重音服务句意；已有录音先判断问题，生成或录制时先试当前任务的代表句，确认自然再批量应用，避免把所有句子套成同一种语气。
- 排练稿按需用 `/`、`//` 和粗体标停顿、重读；生成输入去掉排练符号，节奏转换为模型实际支持的标点、分段或控制。保留措辞和声线，不刻意模仿他人的口头禅。

交流感方法来源：[Tom不是Harry 的口播分析视频](https://www.bilibili.com/video/BV1hWEs6BE5F/)。此处是方法转化，并加入 Clark 的本地工作约定；该期未讲明的设备品牌和音频处理配方不补猜。

## 试听与交付

- 有真实录音先做局部去噪、均衡、动态和响度处理，保留原始文件及可回退版本。接近响度比较前后，听清晰度、泵动、金属感、齿音和句尾；不以转写正确或响度达标代替听感。非必要不新增 AI 口播，内容缺失或修复无效时再按当前授权补录或代配。
- 不看稿听数字、地名、停顿、语气和完整语义；太赶就删重复、拆句或留停顿，太平就调整信息轻重，有念稿感先改成平时会说的话。ASR 只辅助核对内容，转写正确不等于听感合格。
- 结合画面听，检查句子是否说到对应对象、是否挤满画面、是否压住有内容的现场对白和自然声。出镜片段额外看眼神、表情和口型是否自然。
- 修改后连着前后句试听；未听部分明确标记。用户已验收内容在适用范围内继续有效，程序完成或技术导出不代表用户试听验收。
- 改稿默认给可直接用的成稿，排练标记按需提供。音频交付本地文件和简明试听入口；生成记录、局部重做版本及稳定句 ID、画面锚点、实际时长的剪辑交接统一按本地代配音流程保存。仅说明影响使用的未确认事实或未试听片段，不附内部过程报告和自评分。

# Clark 本地代配音

实际执行时读取 [本机版本、独立 CLI 与排错命令](local-voice-cli.md)。其中通用脚本可传入模型、参考和输出路径，无需复制旧项目批处理。

## 参考录音先验收

- 先检查已有录音；需要重录时先试录一小段，听混响、噪声、爆音、削波、距离和语气，再录完整稿。需要真人录制或提词细节时读取 [真人录制与提词](live-recording.md)。
- 从参考中挑干净、连续、自然的片段，长度遵循实际模型要求，不把更长等同更好。保留原录音、处理版、准确转写、源入出点、音频格式和适合的语气；参考转写必须对应实际选段。
- 浴室等明显回声先考虑换安静、软装较多的录音环境。去混响/降噪只作保守对照，比较是否损伤声线和辅音，不能默认增强越强越好；需要重新采集时说明具体问题。

## 模型复用与少量试音

- 查本地模型手册和项目已确认选择，核实权重、环境、参考音频和实际推理模式。主用与备选模型按本地已确认的试听记录选择；后续相似任务优先小样复用，不宣称是所有内容的最佳模型。
- 常规代配音优先沿用已验收的参考音频条件推理。明确是否仅在推理时输入参考音频/文本/音色特征，还是实际进行了参数训练；不能把提供录音或生成特征说成后训练。训练、微调和新增模型部署需符合当前任务范围，不自动开展。
- 用当前任务的代表性句子试音：普通叙述、情绪变化、数字/地名和中英混读按实际需要覆盖。已有合格音色只做针对性检查，不要求每个项目重跑完整盲测。
- 需要比较模型时使用相同内容和尽量可比的参考条件、音量与后处理，本地 HTML 随机隐藏身份，支持音色相似度、准确性、自然度、风格、偏好和备注，允许平局及都不满意。映射键独立保存；模型要求的参考差异记入记录。
- 按题材和句子分析结果，不用平均获胜覆盖个别失败；没有明确优势就保留备选。短样听感合格再批量生成，用户的原有验收在适用范围内继续有效。

## 读音与逐句生成

- 项目维护读音/表达偏好：原词、实际朗读写法、字幕显示、适用语境、用户确认或待试听状态。例如技术词 Transformer、Token、KV Cache 在完整句中试听；数字、单位、缩写及外语地名逐项核对。
- 区分发音错误与文案不像本人。前者调读法或生成控制，后者先改稿；不要对同一坏句无限抽样。已认可的项目措辞仅在适用语境复用，不强制覆盖后续所有表达。
- 使用稳定句 ID，分别记录原话/原始转写、narration_text、subtitle_text（未覆盖时随朗读文字）及导演备注；备注包含语气/重音、对应画面对象或事件、画面锚点和需避让的现场声。遵守主文件的朗读/字幕分工和真实对话边界，生成输入只取朗读文字，并使用模型真正支持的控制。
- 保留语义上下文，分句不能碎到失去语调；缓存记录文案、参考音频内容标识及转写、模型/权重/代码版本、推理模式、随机种子（可用时）、参数和后处理。相关输入改变才重做，已验收输出保留，避免覆盖后无法比较。
- 优先修复有问题的一句并试听前后衔接；模型依赖跨句上下文时重做受影响的最小语义段。先改表述、停顿或参考，再考虑备选模型；跨模型接句要检查音色、响度和空间感，不能因单句正确破坏整体一致性。
- 只删除词句且已有音频存在自然断点时，可先剪掉对应音频，保留正常停顿并连同前后句试听；切点破坏语气或连读时，再生成最小完整语义段。不能只凭转写时间戳判定剪接自然。

## 两层验收和声画同步

- 内容层：本地转写辅助查漏字、重复、错字、数字和外语。识别器不确定或专业词异常时回听，不自动依据 ASR 改写正确音频；风声遮盖的现场对白请用户确认，不臆造。
- 听感层：执行主文件“试听与交付”，额外检查参考音色相似度与生成伪影。
- 局部重做保持原句 ID，保留旧版并标明替换音频路径；向剪辑环节交付受影响句子的 ID、画面对象/锚点和实测音频时长，由剪辑技能同步时间线。只改字幕或导演备注且不影响朗读时，不重新推理；有时序变化仍通知剪辑同步。
- 交付所需本地音频和简明试听入口；批量审阅可附带时码的文字稿。内部参数、故障排查和自评分不塞进观众看到的成品。

## 本地隐私与下载

- 遵守主文件的本地隐私约定；盲测页面也不引入会传出私有内容的外部服务。
- 推理优先复用本地完整权重与环境，检查意外下载和联网行为，使用可用的离线配置；不能仅因工具名写着“本地”就判定无外传。
- 确需下载时，优先国内官方源，只为下载子进程处理应用代理，并核查实际域名、重定向/CDN 路由。清除代理变量不等于已绕过系统 VPN；按主文件的下载边界决定是否继续。
